# 解压砖块 · 微信小游戏版

这是网页版《解压砖块》（100 关 + 每日关卡）的微信小游戏移植版，放在仓库 `wechat-minigame` 分支的根目录下，主分支的 GitHub Pages 网页版不受影响。

## 导入与上传到开发版本（需在你自己的电脑上做）

1. 在微信开发者工具里，用注册该小游戏账号的微信扫码登录（不是账号密码登录）。
2. 左侧选“小游戏”，点“导入”，选择本仓库 `wechat-minigame` 分支检出后的根目录文件夹（里面有 game.js、game.json、project.config.json），AppID 已填好：`wx6476ce5a73237a36`。
3. 导入后在开发者工具里点“上传”，上传成功后，到微信公众平台小程序后台 → 版本管理 → 开发版本，就能看到这个版本，之后才能在该版本上点“提交审核”。
4. 上传到开发版本不等于审核通过，更不等于发布；发布还需版本审核通过 + 备案完成。类目请按实际玩法选休闲类，个人不支持文化互动、角色类、牌类。

## 安全说明

- 本项目只含 AppID。AppID 是小游戏的公开标识，写在 project.config.json 里是正常做法。
- 本项目不含 AppSecret，也不含任何账号密码。AppSecret 是服务端接口密钥，开发者工具上传不需要它，请不要把它发给任何人、也不要写进代码或仓库。
- 进度、每日最佳、尝试次数、音效和瞄准线开关存在微信本地存储（wx.setStorageSync），与网页版 localStorage 不互通，换设备或换账号会重新开始。

## 环境标记：测试 / 生产

- `js/textConfig.js` 最上面的 `env` 就是环境变量：`'production'` 是生产环境（正常顺序锁定），`'test'` 是测试环境（全部 100 关不锁定，可直接点开任意关真机测试）。
- 真机测试时把 `env` 改成 `'test'`，重新编译即可；首页和选关页会显示“测试环境 · 全部关卡已解锁”。测试环境通关只记最佳时间，不推进真实解锁进度，改回生产环境后真实进度不受影响。
- 提交审核 / 上传正式版本前务必改回 `'production'`，否则所有关卡都会直接解锁。

## 文字提示配置文件

- 首页防沉迷提示和适龄提示的文字全部取自 `js/textConfig.js`，改那个文件就可以，改完重新编译即可，不用改 `js/game-core.js`。
- `js/textConfig.js` 里有健康提示标题/正文、适龄提示标题/8+ 徽章/副标题/正文/按钮/关闭文案、进度存储小字。

## 防沉迷与适龄提示

- 首页底部有半透明健康游戏提示框：适合 8 岁以上玩家，含抵制不良游戏、适度游戏等提示语。
- 游戏中点右上角“暂停”进入设置页，点“适龄提示 · 8+”可查看适龄提示弹窗（8+，按本游戏实际内容勾选：无血腥暴力、恐怖、赌博、色情，无内购与聊天功能）。

## 61-100 关加固（2026-10-27）

- 61-99 关普通关全部改用完整钢框，底部钢条入口随难度收窄（61-69 关 4 格、71-79 关 3 格、81-89 关 3 格、91-99 关 2 格），并加内部分隔钢条（每条留 3 格缺口，不密封）。
- 钢框内空白处用深海背景砖补满：61-69 关 680 块、71-79 关 720 块、81-89 关 760 块、91-99 关约 781 块，动物图案仍以亮色砖呈现；连锁砖比例降低、装甲比例随难度递增，要塞 70/80/90/100 关结构未动。
- 防卡死复核：61-100 关密封砖均为 0，核心均可达。

## 移植说明

- 逻辑场地仍是 360×640，挡板、球速、砖块类型、95% 获胜、要塞核心、发球限制、自适应助力、超 20 次降档等规则与网页版一致。
- 网页版的 DOM 界面（开始页、选关页、提示卡、暂停页、结算页、HUD）已全部改成 Canvas 绘制 + 触摸命中，存储改成 wx 存储，音频改成微信 WebAudio，触摸改成 wx.onTouchStart/Move/End。
- 选关页为每页 20 关、共 5 页，点“上一页/下一页”翻页；音乐目前仍是隐藏停播状态，与网页版一致。

## 尚未在真机验证的部分

本版只在 Node 模拟环境里做了语法与关卡生成校验，未在开发者工具真机上逐关打通；请在开发者工具里先跑第 1 关、选关翻页、暂停、要塞发球用完重建这几条主流程，再上传。

## 音效

- 音效用微信 WebAudio 合成，无音频文件；首次触摸按下时即创建/恢复音频上下文。启动时调用 `wx.setInnerAudioOption({ obeyMuteSwitch: false })`，iOS 静音键打开时也不静音游戏音效。暂停页“音效 开/关”默认开，存在本机微信存储。

## 首页

- 标题为“解压爆爆砖”，Canvas 粗体描边 + 黄橙渐变模拟卡通艺术字（未引入自定义字体文件）。
- 首页底图：优先用代码包内的 `images/home-bg.jpg`；因 GitHub 快照推送不支持二进制文件，该图同时以 base64 内嵌在 `js/home-bg-data.js` 中，首次加载失败时写入用户数据目录再加载；两者都失败时用 Canvas 程序化背景（同款构图）兜底，首页不空白。
- 首页“开始”直接进入当前关的发球界面，不经过关卡提示卡；选关页点具体关卡仍先显示提示卡。
- 首页不显示测试环境标识与进度存储小字；选关页的测试环境标识保留，测试模式仍可识别。

## 选关页

- 进选关自动停在当前关那一页：只认最后进过的关（提示卡/对局中/暂停回选关就是正在打的那关，结算页回选关就是下一关，每日关或还没进过关时用真实解锁进度），测试环境下通关不推进真实解锁进度时也不会被拽回别的关，上一页/下一页仍可手动翻页；当前关格子用橙色粗边框加右上角圆点高亮，普通关格子下标“当前”，要塞格子仍标“要塞”。
